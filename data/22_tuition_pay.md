# 등록금 납부 안내
- 출처: https://www.seoultech.ac.kr/life/tution/paiement
- 수집일: 2026-09-11

- 통합정보시스템 조회 ( http://suis.seoultech.ac.kr )
- 통합정보시스템 로그인 ⇨ 학사 ⇨ 등록 ⇨ 등록금고지서 조회
- 등록금 고지서 상의 가상계좌 이체 : 국민은행 본인 외 타인 송금 가능 / 타행에서 이체시 수수료 본인부담 / 예금주 : 학생이름
- 신용카드 납부 자세히보기 ※ 신용카드 납부 불가 : 신‧편입생 첫학기, 분할납부 2차~4차, 1학기‧2학기 등록금 최종 수납, 계절학기, 학점인정 등록 등
- 전액면제자 등록: 통합정보시스템 로그인 → 등록 → 고지서조회 → 전액면제자 납부 클릭 → 이번학기 등록 동의 클릭 후 저장 (또는, 고지서 출력하여 은행에 방문하여‘수납필 도장’처리 *0원 금액은 인터넷뱅킹 및 계좌이체 거래 불가능하여 직접 방문)
- 기타 인터넷뱅킹, 은행창구 방문납부, CD/ATM 납부 등
- 납부 확인방법 통합정보시스템 로그인 ⇨ 등록 메뉴에서 [등록금납부조회] 선택 ⇨ 연도별 금액정보 확인(미등록시 해당 학기 조회되지 않음) ※ 은행 수납내역을 납부 다음날 받기 때문에 수납여부 당일 확인 불가, 당일 확인은 납부은행 문의
- 인터넷 증명발급 ( https://docu.seoultech.ac.kr/intro.html )
- 출력방법 인터넷 증명발급 ⇨ 무료 인터넷 증명발급 ⇨ 인터넷발급바로가기 ⇨ 로그인(학번/ 비밀번호 입력) ⇨ 증명서 신청 ⇨ 신청 ⇨ 교육비납입증명서 선택 ⇨ 연도 및 학기 선택 후 신청 ⇨ 증명서보관함 증명서 보기/출력
- ※ 재학생만 발급 가능(신입생은 학번이 부여된 이후 발급 가능) ※ 표기금액 이상 문의 - 재무과(02-970-6128) / 증명발급시스템(로그인 아이디 ‧ 비밀번호 등) 문의 - 정보전산원(02-970-9060)
- 연말정산 간소화서비스용 교육비 납부 내역 안내
- - 교육비 납부 내역은 등록금 납부 다음 연도 초 국세청 홈텍스에 일괄 업로드함 - 업로드시 장학금, 학자금 대출 제외한 실자부담금액을 업로드함 - 자녀 교육비 내역은 국세청 홈텍스에서 자녀분의 소득세액공제자료 제공 미동의시 확인 불가
